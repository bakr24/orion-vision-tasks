# New Hassan Electronics

A modern and responsive website for **New Hassan Electronics**, an electronics wholesale supplier. The website showcases the business, its products, categories, brands, services, and contact information.

## Features

* Responsive navigation bar with mobile menu
* Modern hero section
* About Us section
* Featured products section
* Product categories with images
* Moving brands marquee
* Why Choose Us section
* Contact section
* Responsive design for desktop, tablet, and mobile devices


## Technologies Used

* React.js
* Vite
* CSS3
* React Icons
